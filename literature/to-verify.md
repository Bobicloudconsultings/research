# Literature To Verify

## Purpose

This file contains literature that was identified during the early stages of the SENSS redesign but has **not yet been verified sufficiently for formal inclusion in the proposal bibliography**.

These sources should not be cited in the final proposal until their:

- authorship;
- publication year;
- exact title;
- journal/book/report;
- volume and issue;
- page numbers;
- DOI or stable publisher record;
- publication status

have been confirmed.

## Verification rule

A source should be moved from this file to `references.md` only after its bibliographic record has been independently confirmed.

Verification should ideally use:

1. the publisher/journal;
2. DOI/Crossref;
3. PubMed or another recognised scholarly database where appropriate;
4. a university repository for the author's accepted manuscript;
5. an official research organisation for reports/projects.

A source being visible on ResearchGate, Google Scholar, a citation list, or a secondary website is **not by itself sufficient** to treat the reference as verified.
